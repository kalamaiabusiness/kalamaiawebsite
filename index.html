A FEW QUICK ANSWERS

Good to know.

Is this a live ordering system yet?

This starter includes a working demo interface. Connect your deployed Google Apps Script endpoint and configure the spreadsheet before accepting real orders.

How do I track a shipment?

Open “Track an order” and enter your order reference and the matching email address. The live backend should only return orders when both values match.

How are refund requests handled?

Requests are submitted for review. The team should approve or reject them in the admin workflow; this portal does not automatically issue money.
